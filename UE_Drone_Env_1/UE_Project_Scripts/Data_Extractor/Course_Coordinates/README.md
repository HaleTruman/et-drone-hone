# Course Coordinates Extractor

## Targets (torus rings)
Extracts target ring transforms from a chosen UE level into a JSON report (for downstream planning).

**Captured per target (world space, cm):**
- `position_cm`: `{x,y,z}`
- `axis_x`, `axis_y`, `axis_z`: world-space unit vectors (Forward/Right/Up)

**Target selection**
- Scans all level actors and includes only actors whose `StaticMeshComponent.StaticMesh` equals:
  - `/Game/AutoGenerated/RedSphere/SM_Torus_1mOpening`

**Ordering**
- Course order is not defined yet; output is sorted deterministically by a simple spatial heuristic: `position_cm.x`, then `y`, then `z`.

## Script
`extract_targets_torus_axes.py`

### Args
- `--level` UE level package path (default `/Game/SimBlank/Levels/SimBlank`)
- `--mesh` torus StaticMesh asset path (default `/Game/AutoGenerated/RedSphere/SM_Torus_1mOpening`)
- `--output-dir` absolute output folder path (required; e.g. `<repo>/Path_Optimizer/course_model`)
- `--compact` write compact JSON (default is pretty)

### Output
Writes:
- `targets-<LevelName>-<YYYYMMDD_HHMMSS>.json`

Top-level fields:
- `frame: "unreal"`, `units: "cm"`, `targets: [...]`

## Run (formal)
```bash
python3 UE_Automation/run_unreal_editor.py \
  --script "$(pwd)/UE_Drone_Env_1/UE_Project_Scripts/Data_Extractor/Course_Coordinates/extract_targets_torus_axes.py" \
  -- --level /Game/SimBlank/Levels/SimBlank \
     --mesh /Game/AutoGenerated/RedSphere/SM_Torus_1mOpening \
     --output-dir "$(pwd)/Path_Optimizer/course_model"
```
