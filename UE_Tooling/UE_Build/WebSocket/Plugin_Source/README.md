# Plugin_Source

Place the hand-edited `DroneWebSocket` plugin source here as tooling-side source-of-truth:

- `Plugin_Source/DroneWebSocket/DroneWebSocket.uplugin`
- `Plugin_Source/DroneWebSocket/Source/DroneWebSocket/...`

Use `../bootstrap_plugin.py` to install this source into `UE_Drone_Env/Plugins/DroneWebSocket`.
Use `../plugin_validate.py` to confirm the installed project plugin is in sync, built, and startup-ready.
