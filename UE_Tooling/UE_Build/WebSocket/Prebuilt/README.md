# Prebuilt

Optional location for prepackaged plugin payloads:

- `Prebuilt/DroneWebSocket/DroneWebSocket.uplugin`
- `Prebuilt/DroneWebSocket/Binaries/...`
- `Prebuilt/DroneWebSocket/Resources/...` (optional)
- `Prebuilt/DroneWebSocket/Content/...` (optional)

Use `../deploy_prebuilt_plugin.py` to deploy this payload into `UE_Drone_Env/Plugins/DroneWebSocket`.
