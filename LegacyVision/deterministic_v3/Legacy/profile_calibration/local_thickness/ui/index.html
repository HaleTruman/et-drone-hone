What the panels mean. Distance-to-background is the direct transform and only behaves like an inscribed radius at medial locations. Covering local thickness spreads twice the largest covering-disk radius over every foreground pixel.

Empirical thickness bands. The absolute map uses the measured tie-preserving boundaries 6.25, 8, 10, 12, 14, 16, 18, 21, 25 px. They are physical wall-scale evidence and are not renamed production profile IDs.

Adaptive routing. The recommended rule converts smoothed local thickness to equivalent_area = component.area_px × (local_thickness / component_P50)², resolves that area through the current production profile limits, and clamps the result to the component baseline ±2 profiles.

Two-population attempt. The thinner and thicker panels show each accepted thickness population as black over the exact white closed_mask. Both sides require at least 10%/24 px support, a 1.25× median separation, and 35% explained variance. They remain thickness classes, not gate identities.

Regional density evidence. The composite lazily reuses each selected production DensityEvidence.final_field variant, selects it spatially, and recomputes P70/P80/P90 within each connected same-profile region. The source fields still use the complete connected-component mask so shared occlusion evidence is retained.

Clipped overlap review. A clipped candidate is retained only when its complete supporting annulus lies inside the recorded frame. It is shown in magenta and remains routing_eligible=false; incomplete clipped evidence stays indeterminate. JavaScript only displays server-authored results.
